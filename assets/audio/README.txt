Background music
================
The site plays assets/audio/bgm.mp3 when a visitor presses the music (♪) button.

To change the music:
  1. Put your own .mp3 file in this folder.
  2. Name it bgm.mp3 (replace the existing file), then commit and push.

Or keep your own file name and change MUSIC_SRC at the top of assets/js/site-extras.js.
Use music you have the right to publish (your own, royalty-free or licensed).

The current bgm.mp3 is an original placeholder loop generated for this site.
